# SamaLite 0.7.0

圆屏下半区重新分组，转速与网速数字增大至42px、总览FPS增大至58px，主要图标/单位增大至20/18px。CPU/GPU标记移到圆环下方，中央时刻增大至28px；下半区内容扩展到更靠近圆边的位置。

- 默认自动游戏布局：前台全屏客户区或指定进程持续至少3秒有真实Present帧事件后触发，失去证据超过8秒恢复，切换时间受刷新周期影响。
- 游戏布局使用86px FPS、48px帧时间和1% Low，保留温度、占比、功耗和风扇/水泵；收起网络、存储、DIMM及核显读数。
- 支持自动、固定总览、固定游戏三种模式；窗口化游戏可指定进程名。现有自定义槽位、刷新、方向、亮度及自启设置保持。
- 使用Windows公开窗口/显示器接口及PresentMon，无截屏、游戏注入或NVIDIA私有识别依赖。这是全屏渲染启发式，不保证识别所有游戏；非游戏全屏渲染也可能触发，多进程浏览器不保证触发。

89项离线检查通过，覆盖全屏边界、真实帧确认、切出回滞、长间断、三种显示模式、极值栅格及新旧布局局部清除。管理员隐藏DXGI测试产生946次Present，取得FPS/帧时间/1% Low并成功触发游戏布局，测试窗口从未显示，退出码0；未启动真实游戏做兼容性验收。上半内容保持r216，下半扩展至r238，实体屏边框遮挡仍需观察。

仍为复用.NET 10桌面运行时和已有PawnIO的免安装目录包，不进行单文件临时解包。用户数据位于EXE旁data/，ZIP不含本机配置和日志。
