# SamaLite 0.6.1

圆屏改为上半区双层粗环与中央大温度：左侧CPU/RAM、右侧GPU/VRAM，统一向顶端100%增长。外环16px、内环14px，百分比随进度末端移动，拥挤时引线避让。

- CPU/GPU温度从38px增大至74px；不再以大数字重复展示四项占比。
- 下半区采用直线分组：散热在左、帧表现居中、网络和存储在右；普通数字30px，中央最高42px，图标和单位放在下方。
- 保留12个自定义槽位及3种预设；已有自定义顺序、刷新间隔、亮度、方向、自启和采集设置保持。
- 关闭环带时提供固定百分比行；缺失和过期显示—，有效零值保留。

75项离线检查通过，包括全部0–100整数占比对的标签避让、同为100%时分离、七组极值栅格、r216安全圆、局部刷新覆盖和暂停/重连。未打开验证窗口；实际斜视阅读仍需用户观察。采集方式与0.6.0相同。

仍为复用.NET 10桌面运行时和现有PawnIO的免安装目录包，不进行单文件临时解包。设置保存在EXE旁data/；PresentMon按需后台运行。
