# SamaLite 0.6.0

480×480圆屏改为固定CPU/GPU大数字、RAM/VRAM容量条、可选边缘占比条和12个彩色图标指标槽，支持硬件总览、游戏、散热预设与逐槽配置。

- 新增CPU风扇/水泵RPM、NVMe综合温度、单网卡上下行、全部物理磁盘读写与活动率。
- 新增按需PresentMon应用FPS、平均帧时间、逐帧1% Low；固定官方2.6.0独立console，随包约0.94 MiB，无GUI/服务/RTSS安装，不写CSV。
- 主窗口提供布局和数据源编辑；传感器无法确认、失败或过期显示—。风扇名称不能证明实际接线。1% Low至少100帧/5秒，最多60秒/120000帧，不等同显示或插帧FPS。
- 托盘、硬件分组、显存/DIMM/核显详情、暂停冻结、重连、关注提示及最近成功帧预览一起交付。
- 目录版复用本机.NET 10桌面运行时与独立PawnIO；数据在EXE旁data/，无单文件自解压。Startup.ps1可设置当前用户登录15秒后静默提权启动。

验证：63项离线检查通过；3种预设与极值均在r216安全圆内；后台实际CPU/DIMM/显存/核显、转速、两块NVMe和IO有效；完成发送持续推进，设备返回needReSend:0。受控隐藏DXGI测试捕获真实Present事件与全部3项帧统计，未显示窗口，退出无自有ETW残留。未完成真实游戏、实物斜视可读性、完整DPI矩阵、物理拔插/休眠和长时间验收。

候选版后台短测：工作集147.60 MiB、私有提交93.30 MiB、总CPU约0.152%，未运行帧采集子进程；此数字不是长期上限，也未达到旧SAMA约55 MB工作集。独立TEMP/TMP和.NET解包目录约61秒无文件创建/重命名或残留。绿色包约2.9 MiB，解压约7.6 MiB；不含本机设置或采样记录。
