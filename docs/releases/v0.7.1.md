# SamaLite 0.7.1

区分圆屏网速与磁盘吞吐，并更换应用图标。

- 网速保留绿色上下箭头；底部磁盘读写使用橙色磁盘与方向图标，数值和单位同步改为橙色。向下读取，向上写入，单位仍按MiB/s与KiB/s自动切换。
- 应用图标改为深色圆形水冷监控屏、蓝紫弧带和装饰温度数字。16/20/24像素托盘使用简化温度计，保留连接、暂停、断开及关注的形状标记；ICO提供16至256像素8种尺寸。
- 图标生成和ICO回读检查移入默认离线验证，全程无需打开测试窗口。

90项离线检查通过，已检查普通与极值圆屏、小尺寸托盘及应用图标。设置、自启、自动游戏布局和采集方式保持；发布包继续使用已有.NET 10桌面运行时和PawnIO，不进行临时自解包。
